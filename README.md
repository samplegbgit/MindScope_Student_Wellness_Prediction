# MindScope — Student Wellness Prediction

A machine learning–based web application that predicts student wellness scores using lifestyle habits, academic information, stress levels, and social media usage patterns.

## Live Demo

🔗[Live Demo](https://mindscope-student-mindpulse.onrender.com)

## Features

- ML-based student wellness score prediction
- Lifestyle and digital usage assessment
- FastAPI-powered prediction API
- Interactive web interface
- Prediction history and visualizations

## Tech Stack

- **Languages:** Python, JavaScript
- **Machine Learning:** Scikit-learn
- **Backend:** FastAPI
- **Data Processing:** Pandas
- **Frontend:** HTML, CSS, JavaScript
- **Model Serialization:** Joblib

> **Disclaimer:** This project is for educational purposes and is not a medical diagnostic tool.
